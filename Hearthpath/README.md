# Hearthpath (old saved data)

A stand-in add-on with no game code, published by Ostrowski Holdings LLC. Panoply Suite used to be called
Hearthpath. The game finds saved data by the add-on folder's name, so this folder keeps the name
`Hearthpath` and its TOC lists the old saved-data names (`HearthpathDB`, `HearthpathAuctionDB`,
`HearthpathReportsDB`, and per character `HearthpathCharDB`). That keeps your old settings, routes, quest
records, auction history and reports loading, so Panoply Suite can bring them across.

- Keep it installed and turned on. Panoply Suite copies the old data once, checks the copy, and never
  changes the old data.
- It is not the old Hearthpath add-on and must never be replaced by it (the installer moves the old one
  aside and keeps it in its backup).
