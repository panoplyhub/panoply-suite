# Panoply Suite

Panoply Suite is a leveling route, arrow, professions, bags, merchant, gathering and waypoints
add-on for World of Warcraft. It is free and open source (GNU General Public License, version 3
only — see `LICENSE`). It is free now and free forever.

It is for **WoW Forever** now. Classic support is coming later.

## Install

1. Download the release zip (`PanoplySuite-0.9.9.4.zip`).
2. Quit World of Warcraft.
3. Copy the folders `PanoplySuite`, `PanoplySuite_QuestData`, `PanoplySuite_RouteData`,
   `PanoplySuite_Plans` and `PanoplySuite_Languages` into `_forever_\Interface\AddOns` inside your
   World of Warcraft folder.
4. Only if you are upgrading from an earlier Panoply Suite or Hearthpath: also copy the `Hearthpath`
   and `Polestar` folders. They are small stand-ins that keep your old saved settings loading.
   **If you installed the Polestar add-on yourself, leave your own `Polestar` folder alone** and do not
   copy ours over it.
5. Start WoW Forever, open AddOns on the character screen, and make sure Panoply Suite is ticked.
